Este repositório contém uma API REST desenvolvida em **Go (Gin Framework)** com **PostgreSQL**, equipada com uma esteira automatizada de **Integração Contínua (CI)** via GitHub Actions.

---

## 📌 Visão Geral da Esteira de CI

A pipeline foi projetada para garantir **qualidade de código**, **execução de testes automatizados** e **geração de artefatos compilados** a cada alteração na branch principal (`main`).
